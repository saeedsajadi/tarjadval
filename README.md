# سازنده جدول

ابزار مرورگری برای ساخت جدول با همگام‌سازی متن و جدول، واژه‌نامه فارسی به انگلیسی، و ترجمه با API سازگار با OpenAI.

## اجرا

فایل `index.html` را مستقیماً در مرورگر باز کنید. برای استفاده از API ترجمه، آدرس، توکن و شناسه مدل را در تنظیمات وارد کنید. تنظیمات در `localStorage` مرورگر ذخیره می‌شوند؛ توکن به‌صورت متن ساده ذخیره می‌شود.

## ساختار پروژه

```text
index.html             ساختار صفحه و بخش‌های رابط کاربری
assets/css/styles.css  ظاهر، چیدمان و حالت‌های واکنش‌گرا
assets/js/app.js       همگام‌سازی جدول، واژه‌نامه، ترجمه و تعاملات رابط
```

پروژه وابستگی یا مرحله build ندارد و فایل‌ها به‌صورت ایستا در مرورگر اجرا می‌شوند.
